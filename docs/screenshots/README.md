# Screenshot

File SVG di folder ini adalah **placeholder** agar README tidak menampilkan
gambar rusak. Ganti dengan tangkapan layar asli setelah aplikasi berjalan.

Saran nama file:

- `dashboard.svg`
- `history.svg`
- `skill-gap.svg`
- `upload-review.svg`

Cara mengambil screenshot:

1. Jalankan `docker compose up --build`.
2. Buka `http://localhost:5173`, daftar, dan unggah CV dari `demo/`.
3. Ambil screenshot halaman Dashboard, Riwayat, Roadmap, dan Upload/Review.
4. Simpan dengan nama di atas (PNG juga boleh; sesuaikan tautan di README).
