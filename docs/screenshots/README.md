# Screenshot

Tangkapan layar asli aplikasi CareerLens AI, diambil pada viewport 1440×900
(tinggi penuh halaman) setelah menganalisis CV fiktif dari `demo/`.

- `dashboard.png` — Dashboard dengan gauge skor, breakdown, radar coverage,
  top lowongan, dan skill gap.
- `history.png` — Riwayat dua analisis dan perbandingannya.

Cara mengambil ulang:

1. Jalankan `docker compose up --build`.
2. Buka frontend (`http://localhost:5173` atau port `FRONTEND_PORT`), daftar,
   lalu unggah CV dari `demo/`.
3. Buka halaman Dashboard dan Riwayat, ambil screenshot tinggi penuh pada
   lebar 1440 px.
4. Simpan sebagai PNG dan sesuaikan tautan di README jika nama berubah.
